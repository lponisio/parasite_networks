# No universal network predictor of disease risk in plant–pollinator communities

Rose McDonald, Jesse Fan Brown, Nicole Martínez-Llaurador, Shalene Jha, Julia Jones, Katie Moriarty, and Lauren C. Ponisio

This repository contains the R code for a study of how plant–pollinator network structure and landscape context relate to bee parasite prevalence. The study pairs 6,629 parasite screenings with 281 plant–pollinator networks across five landscapes. The analyses examine *Crithidia* spp. and *Apicystis* spp. in *Bombus*, *Apis*, and *Melissodes* and evaluate whole-network structure, species-level network roles, and floral overlap with feral honey bees.

## Setup

Use R with the packages loaded by the scripts and the helpers in `src/`. Compilation and network metrics use packages including `tidyverse` and `bipartite`. Phylogenetic preprocessing uses `ape`, and the PCA script uses `princomp()` with `factoextra` for plotting. Model fitting requires `brms` and a working Stan toolchain. The model scripts also use packages including `glmmTMB`, `performance`, `posterior`, and `bayesplot` for fitting, diagnostics, and summaries. See each script and its sourced helpers for the packages needed for that step.

Start R in the `parasite_networks/` repository root. The supplied `lab_paths.R` selects a Dropbox path based on the computer name. For your local setup, replace the contents of your copy of `lab_paths.R` with a single line and use your own parent directory:

```r
local.path <- "/path/to/projects"
```

For example, if the repository is at `/path/to/projects/parasite_networks`, use `/path/to/projects` as `local.path`. If you are rebuilding the compiled data, put `parasite_networks_saved/` in that same parent directory. Start each script that calls `source("lab_paths.R")` from the repository root so it can find the file.

For scripts with hard-coded Dropbox paths, replace the initial `setwd()` call or calls with `setwd("/path/to/projects/parasite_networks")`. Make sure the helper scripts and inputs are available at the relative paths used in the code. Create `saved/` and `figures/` if needed for model outputs and plots. The network visualization script writes PDFs under `figures/networks/`.

## Data

### Files in `parasite_networks/data/`

| File | Contents and use |
| --- | --- |
| `network_mets.RData` | Whole-network metrics joined to parasite screening summaries and survey data. Input to `4_network_models.R`. |
| `sp_mets.RData` | Species-level network metrics joined to parasite screening summaries and survey data. Input to the PCA, species-level models, and population-genetic models. |
| `sp_genus_site_mets.RData` | Compiled parasite screening summaries used in the exploratory plots. |
| `raw_mets.RData` | Intermediate whole-network metrics calculated from the interaction networks before joining the screening data. |
| `raw_sp_mets.RData` | Intermediate species-level network metrics calculated before joining the screening data. |
| `SI_popgen.RData` | Site-level population-genetic metrics used in the *Bombus* analyses in `6_popgen_models.R`. |
| `BEE_mat7_fulltree.nwk` | Full bee phylogeny in Newick format. Input to `2_makePhylogeny.R`. |
| `Bombus_phylogeny.Rdata` | Pruned *Bombus* tree and phylogenetic covariance matrix used in species-level modeling. |
| `Melissodes_phylogeny.Rdata` | Pruned *Melissodes* tree and phylogenetic covariance matrix loaded by the species-level modeling script. |

Use the compiled files to start at the relevant analysis stage. The interaction-network visualization in `10_networks_vis.R` also requires `data/allNets.RData`, which is generated by `0_compile.R`. A section of `11_publication_tables.R` reads `../sunflower/data/spec_RBCL_16s.Rdata`.

### Raw inputs in `parasite_networks_saved/`

To rebuild the compiled data, place `parasite_networks_saved/` alongside `parasite_networks/`. At the root of `parasite_networks_saved/`, `stands.csv` supplies stand metadata and subproject assignments for the Pacific Northwest records. The compilation script assigns screening and network files to projects by their positions in the directory listings. Keep each input folder limited to the corresponding files listed below.

#### `screenings/`

Each file contains project-level parasite screening summaries loaded by `0_compile.R` as `all.sums`. The rows below follow the load order.

| File | Study system |
| --- | --- |
| `HJA_parasite_sums.Rdata` | Cascades Meadows at H.J. Andrews Experimental Forest |
| `PN_parasite_sums.Rdata` | Pacific Northwest working forests |
| `SF_parasite_sums.Rdata` | Sunflower Fields |
| `SI_parasite_sums.Rdata` | Sky Island Meadows |

#### `networks/`

These R data files store plant–pollinator interaction networks in an object named `nets`. The table follows the order expected by `0_compile.R`.

| File | Study system |
| --- | --- |
| `HJ_YearSR_PlantPollinator_Bees.Rdata` | Cascades Meadows at H.J. Andrews Experimental Forest |
| `PN_YearSR_PlantPollinator_Bees.Rdata` | Pacific Northwest working forests (Coast Range Harvested Forests and Cascades Post-fire Harvested Forests) |
| `SF_YearSR_PlantPollinator_Bees_incApis.Rdata` | Sunflower Fields (includes *Apis*) |
| `SI_YearSR_PlantPollinator_Bees.Rdata` | Sky Island Meadows |

The compilation script combines these network lists, keeps networks with at least three plant and three bee taxa, and retains those with matching keys in the compiled parasite screening data. It saves the resulting list as `parasite_networks/data/allNets.RData`.

#### `popgen/`

`0_compile.R` reads `popgen/SI.csv`, which stores Sky Island *Bombus* population-genetic metrics by species and site in `Site_*` columns. The script reshapes the table and saves it as `parasite_networks/data/SI_popgen.RData`. `SI.xlsx` is a companion spreadsheet. `popgen_bombus.csv` contains a table that brings together *Bombus* population-genetic metrics and parasite screening counts.

#### Map project

`all_projects_map.qgz` is the QGIS project for the study map. Reopening the map with its layers requires access to the spatial data referenced by the project.

## Analysis workflow

Run the scripts for the stages you need, using the order below when starting from the original inputs. With compiled data in place, begin at the relevant analysis. With saved model objects in place, begin at the corresponding figure or table script.

| Stage | Script | Purpose |
| --- | --- | --- |
| Compile inputs | `0_compile.R` | Combines parasite screening records and interaction networks across projects, calculates network metrics, and prepares the analysis objects in `data/`. |
| Inspect compiled data | `0_visualization.R`, `1_exploration.R` | Plot network metrics across projects and explore parasite prevalence and network structure. |
| Prepare phylogenies | `2_makePhylogeny.R` | Prunes the bee phylogeny to the focal species and saves trees and phylogenetic covariance matrices. |
| Examine correlations | `3_pcas.R` | Visualizes correlations among species-level network metrics and runs principal component analyses. |
| Fit whole-network models | `4_network_models.R` | Models parasite prevalence using whole-network metrics and landscape context. |
| Fit species-level models | `5_species_network_models.R` | Models parasite prevalence using host species’ positions and floral use within interaction networks. |
| Fit population-genetic models | `6_popgen_models.R` | Uses the compiled population-genetic data to examine parasite prevalence in *Bombus*. |
| Plot model results | `7_network_model_viz.R`, `8_species_network_model_viz.R`, `9_model_vis_pop.R` | Read saved model objects and plot results for the whole-network, species-level, and population-genetic analyses, respectively. |
| Draw interaction networks | `10_networks_vis.R` | Uses compiled network and species data to visualize plant–pollinator interactions. Rendering the network widgets to images uses `webshot2` and a compatible Chrome or Chromium installation. |
| Summarize study data | `11_publication_tables.R` | Summarizes survey effort and other study data for manuscript tables using saved model data and project inputs. |
